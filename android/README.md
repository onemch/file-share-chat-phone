# 文件共享中心 · Android 原生 App

**这个 App 自己就是一台服务器。** 安装后启动，App 内嵌的 HTTP + WebSocket 服务会监听 `0.0.0.0:5000`，其他手机（或电脑）连同一个 WiFi 打开 `http://手机IP:5000` 就能共享文件与群聊；App 里也能在「连接」页填别人的地址，切换成客户端加入对方的共享空间。

## 安装

- 安装包：`android/文件共享中心.apk`（自签名 debug 证书，约 70KB）
- 要求：Android 6.0（API 23）及以上
- 手机上安装时需要在「设置 → 安全」允许**安装未知来源应用**；或用数据线：
  ```bash
  adb install -r 文件共享中心.apk
  ```
- 首次启动会申请**通知权限**，请允许——前台服务必须显示常驻通知，否则系统可能杀掉服务。

## 使用

| 场景 | 操作 |
|---|---|
| **当主机（服务端）** | 打开 App 即自动启动服务。切到「连接」页能看到本机邀请二维码，点「复制链接」或「系统分享」把带 `?host=` 参数的链接发给朋友，对方点开会自动连上你的手机。保持前台服务通知存在。 |
| **当客户端** | 「连接」页支持扫码、剪贴板自动识别、搜索附近主机（默认扫 `5000/5001/8000/8080`，可自行增删）、手动输入，连上后文件与群聊都指向对方。 |
| **当客户端** | App 内切到「连接」页 → 输入对方主机地址（如 `http://192.168.1.5:5000`）→ 点「连接」。之后文件、群聊都指向对方。 |
| **恢复本机** | 「连接」页 → 「恢复为当前页面所在设备」。 |
| **和 PC 端互通** | PC 端启动共享服务当主机，手机 App 连它；或反过来，手机当主机，PC 浏览器访问。两边 API 完全一致。 |
| **上传** | 文件页「选择文件」可多选；拍照按钮调用系统相机/文件选择；上传进度实时显示。 |
| **下载** | 点击下载后交给系统下载管理器，文件落在「下载」目录，通知栏可查看。 |

共享目录位于：`/storage/emulated/0/Android/data/com.fileshare.phone/files/shared`（卸载 App 会一并删除，重要文件请及时导出）。

## 与桌面/网页版的差异

| 项 | 说明 |
|---|---|
| 邀请二维码 | 「连接」页由前端离线库直接在 canvas 上生成二维码，App 内同样能显示；也可点「复制链接」或用系统分享。 |
| 扫码连接 | App 内自动走「拍照 / 相册选图识别」（WebView 不直接授权摄像头），HTTPS 或浏览器安全上下文下可用实时摄像头。 |
| 顶部状态栏 | 已去掉重复的原生紫色栏，WebView 通过 `WindowInsets` 避开状态栏与导航栏，网页 AppBar 不会再和信号栏重合。 |
| 文件夹上传 | WebView 不支持 `webkitdirectory` 目录选择，Android 端请用「选择文件」多选；「选择文件夹」按钮可能只能选到单个文件。桌面浏览器与电脑版不受影响。 |
| 后台保活 | 使用前台服务（`dataSync` 类型）+ 常驻通知。部分国产 ROM（小米/华为/OPPO/vivo 等）需要在「电池优化 / 自启动 / 后台锁定」里把本 App 设为允许，否则锁屏后服务可能被冻结。**Android 15+ 对 dataSync 前台服务有「24 小时内累计 6 小时」的系统上限**，超时后系统会停止服务；需要长时间共享时，请偶尔打开一次 App 或重启服务。 |
| 服务端口 | 固定 5000，若被占用通知会提示「启动失败」。 |
| 安全 | 无登录鉴权，仅限可信局域网；不要做端口映射到公网。所有上传/下载/删除路径都做了 `..` 穿越校验。 |

## 从源码重新构建

不需要 Android Studio、Gradle 或 Android SDK 完整安装，只需要两个 SDK 组件 + JDK。

```bash
# 1. 首次：下载最小 SDK 组件（约 120MB，放到 temp/sdk/）
bash ../tools/setup-sdk.sh

# 2. 构建（aapt2 → javac → d8 → zipalign → apksigner）
bash build-apk.sh
# Windows 也可双击 build-apk.bat
```

- 编译用 **JDK 8**（`H:/APP/JDK8`），运行 d8/apksigner 用 **JDK 17+**（默认 `D:/App/java21`）。可用环境变量 `JDK_HOME` 覆盖运行 JDK；若没有 JDK 8 会回退，但 d8 8.2 处理 JDK 21 生成的匿名内部类可能报错。
- 输出：`文件共享中心.apk`，已用 debug keystore 做 v1/v2/v3 签名，可直接安装。
- 构建中间产物在 `out/`，可随时删除。

### 源码结构

```
android/
├── AndroidManifest.xml
├── src/com/fileshare/phone/
│   ├── MainActivity.java     WebView 壳、文件选择、下载、地址复制
│   ├── ShareService.java     前台服务，常驻通知
│   ├── ShareServer.java      HTTP 路由、文件增删改查、ZIP、CORS
│   ├── Multipart.java        流式 multipart 解析（大文件不进内存）
│   └── WsHub.java            WebSocket 握手/帧/广播/历史
├── assets/www/              与 static/ 同步的移动端前端
├── res/                     应用名与图标
├── build-apk.sh / .bat
└── 文件共享中心.apk
```

> ⚠️ 本 APK 在此 Windows 环境完成了编译、dex 转换、资源清单、zip 对齐与 v1/v2/v3 签名校验，但**没有真机运行验证**。安装后若发现某机型兼容问题，请用 `adb logcat` 抓日志反馈。
