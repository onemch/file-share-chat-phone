# 2026-11-05

## 新建 file-share-chat-phone（手机版）
- 由 `H:\Code\file-share-chat`（Flask 单文件桌面版，内嵌 1360 行 HTML + tkinter 托盘）改造为独立手机项目，**原项目未改动**。
- 需求澄清结论：用户要「一台手机/设备启动，其他手机访问网页或也装应用加入同一共享文件夹」→ 定为**双角色通用架构**：任意设备跑 `server.py` 当主机（PC / 安卓 Termux / 云），所有手机用浏览器或 PWA 当客户端；iPhone 因 iOS 后台限制只能当客户端。网络先做局域网，前端主机地址可配置，预留外网。
- 关键技术边界：纯 H5/PWA 无法监听端口，手机当主机必须靠本地原生进程（Termux 跑 Python）。
- 实现：Flask + flask-cors + flask-sock；`static/` 无构建链三 Tab 移动 H5（文件/群聊/连接）；PWA manifest + sw（只缓存壳，API 与跨主机请求不缓存）；`?host=` 扫码自动配置主机；`?tab=` 深链；qrcode 生成邀请二维码；`make_icons.py` 纯标准库生成图标。
- 安全加固：`safe_basename` + `resolve_within` 防路径穿越（上传/下载/删除/打包全覆盖），前端 `esc()` / textContent 防 XSS，昵称 latin-1→utf-8 乱码兜底，`after_request` 广播 `files_changed` 实现多端自动刷新。
- 验证：venv 用官方 PyPI 源安装（**全局 pip 被配成清华源，此环境超时**）；py_compile + node --check；全部 HTTP 接口、中文/嵌套文件夹上传、ZIP 打包、路径穿越返回 404、WebSocket 双端广播/历史回放、390×844 手机尺寸截图均通过。
- 已知限制：iOS 不能当主机；无登录鉴权（勿暴露公网）；聊天历史仅内存，重启清空；Termux 切后台可能被系统杀。

## 追加：原生 App（Android APK + iOS Xcode 工程）
- 用户追加要求「安卓和苹果的安装包，手机端既能当客户端也能当服务端」。
- 硬边界：iOS IPA 只能在 macOS + Xcode 签名导出，Windows 物理上无法产出；iOS 后台会挂起 socket，只能前台期间当主机。
- Android 交付真安装包 `android/文件共享中心.apk`（约 70KB，自签名 v1/v2/v3，minSdk23/targetSdk35）：纯 framework Java，**无 Gradle / AndroidX / 第三方库**，App 内嵌 HTTP + WebSocket 服务（`ShareServer/Multipart/WsHub`）+ 前台服务常驻，WebView 壳可当主机也可连别人主机。
- 构建链：`tools/setup-sdk.sh` 从 dl.google.com 下 platform-35_r02 + build-tools_r34（约 120MB 解压后 260MB，留在 temp/sdk）→ `android/build-apk.sh` 用 aapt2 → javac → d8 → 重建 zip → zipalign → apksigner，不需要 Android Studio。
- **构建三个坑（已解决）**：① JDK21 编译的匿名内部类让 d8 8.2 抛 NPE → javac 改用 JDK8，d8/apksigner 仍用 JDK21；② javac `@argfile` 在 Git Bash 下路径解析成 `\h\...` → 改为 shell 展开文件列表；③ Python zipfile 追加 classes.dex 导致 zipalign `header mismatch` 警告 → 改为重建整个 APK zip。
- 验证：aapt2 dump badging 正常、zip CRC 全通过、dex 含 22 个类、v1/v2/v3 签名校验通过；因无法真机运行，另在 JVM 上单测了流式 multipart 解析（中文/嵌套/4096B 二进制）与 WebSocket 帧解码（16 位长度 + mask + 中文）、JSON 转义，均 PASS。
- iOS 交付 `ios/` 完整 Xcode 工程：Swift + Network.framework 手写 HTTP/WS/ZIP，约 2211 行，无 SPM/CocoaPods 依赖，含 Info.plist / AppDelegate / ViewController / 8 个服务端文件 / www 资源；Mac 上选 Team → Archive → Ad Hoc 导出 IPA。
- 前端修复（三端同步）：`/qr.png` 404 时不再隐藏整个邀请卡片（保留「复制访问链接」按钮）；复制链接改用 `/health` 返回的 `lan_ip` 构造，避免把 `127.0.0.1` 分享给别人（App 内嵌服务场景的关键 bug）。
